ShapoGFX demorig (2D skeletal animation for embedded systems, running in WebAssembly)

A DragonBones character converted by dbones2cpp and animated with rig::Instance: 24 fps keyframes interpolated every frame. The (+) / (-) buttons zoom in and out (1/4 to 16 times); drag to scroll. The frame rate is drawn in the top left corner. ?screen=WxH in the URL sets the frame buffer size (default 480x320, e.g. 320x240, 640x360).
